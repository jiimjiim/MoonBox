🌙 MOONBOX 

    一个专为小米Vela/ HyperOS手环/手表打造的极简行情监控应用。

✨ 功能特性

    实时行情：目前支持市值前十的加密货币，可二次开发使之支持A股/美股/期货。

    刷新模式：点击Logo切换刷新频率，最快支持15s自动刷新且屏幕常亮，底部“盈亏同源”字样点击亦可手动刷新。

    置顶排序：长按自选列表即可置顶。

🛠️ 适配

    release有适配圆形/方形版本和单独的胶囊屏版本。
